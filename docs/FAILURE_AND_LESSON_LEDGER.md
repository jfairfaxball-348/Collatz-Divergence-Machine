# Failure and Lesson Ledger

This file is append-only in spirit. Preserve material failures and route kills so future sessions do not reconstruct or repeat them.

Allowed claim statuses:

`PROVED`, `FINITE-VERIFIED`, `COMPUTATIONAL-EVIDENCE`, `HEURISTIC`, `CONJECTURAL`, `FAILED`, `SUPERSEDED`, `UNKNOWN`.

## F0001 — Finite survival does not imply divergence

**Status:** PROVED as a project logic rule.

Any finite trajectory prefix, however long or large, is compatible with later descent. A finite prefix cannot by itself establish an unbounded orbit.

**Action:** every finite computation is labelled finite evidence or finite verification only.

## F0002 — Peak magnitude is not progress by itself

**Status:** PROVED as a project resource rule.

An enormous peak can consume arbitrary-precision resources without revealing a repeatable growth mechanism.

**Action:** promotion must identify expected mathematical information, not merely size.

## F0003 — Prior-project orientation bridge failure

**Status:** FINITE-VERIFIED as an audit fact about the previous repository; not a theorem about Collatz.

The prior cycle project demoted numerical conclusions after identifying an unproved orientation/sign bridge.

**Lesson:** audit implication chains before consuming exact arithmetic downstream.

## F0004 — Local/global hypothesis leakage

**Status:** FINITE-VERIFIED as an audit fact about the previous repository.

A theorem with global hypotheses was not validly reusable from a local condition.

**Lesson:** every symbolic theorem application must list and verify its live hypotheses.

## F0005 — CDM0 calibration is not a search result

**Status:** FINITE-VERIFIED.

The initial small-range calibration exists only to test infrastructure. Any workflow promotions have no divergence significance.

## F0006 — Magnitude-only frontier duplication

**Status:** FAILED as a primary search route.

Peer-reviewed exact computation already covers every start below `2^71`, and a strong current external project report extends slightly farther. Repeating contiguous brute force in the current Python scaffold would spend compute reproducing externally known finite convergence rather than testing a new mathematical hypothesis.

**Action:** use audited external coverage as a provenance-tagged search mask. Do not import it as local certification.

## F0007 — Long parity runs are not divergence structure

**Status:** FAILED as a standalone promotion metric.

For `n = 2^p - 1`, the first `p` shortened-map source states are odd and
`T^j(n)=3^j 2^(p-j)-1` for `0<=j<=p`. Thus arbitrarily long all-odd prefixes can be constructed explicitly while remaining only finite behavior.

**Action:** retain parity-run length as a diagnostic only. Promotion requires a structure that can be continued indefinitely or a separate theorem giving it relevance.

## F0008 — Long finite no-descent and huge finite peak ratios can be manufactured

**Status:** FAILED as standalone promotion criteria.

The same family `2^p-1` has arbitrarily long initial no-descent prefixes and reaches `3^p-1` after `p` shortened steps, so its finite peak/start ratio grows on the order of `(3/2)^p`.

**Action:** `first_descent_time`, `max_excursion`, and `peak_start_ratio` may be calibration labels or outcomes, but none is sufficient by itself for L1->L2 promotion.

## F0009 — External coverage is not local certification

**Status:** PROVED as a project provenance rule; FINITE-VERIFIED as the CDM1 audit treatment of current sources.

A published or official external verified range can suppress redundant discovery work without becoming a locally certified basin entry. The exact claim, map convention, source version/date, and reproducibility class must remain attached.

**Action:** certification-relevant tails must be justified at the required provenance level and replayed locally when the proof depends on them.

## F0010 — Total stopping time is not the primary divergence signal

**Status:** FAILED as a primary ranking route.

A total stopping/delay record can accrue most of its length after the trajectory has already fallen below its starting value. By contrast, a least divergent start, if one exists, can never fall below itself.

**Action:** use first-descent/no-descent structure and exact parity/residue constraints before total stopping-time extremality.

## F0011 — Throughput before filter value is economically backwards

**Status:** FAILED as a project-priority rule.

GPU/distributed engineering can multiply exact finite throughput, but it does not by itself increase mathematical information per tested candidate. CDM1 found no reason to build frontier-scale infrastructure before establishing that a filter or generator predicts anything beyond its conditioning event.

**Action:** calibrate filter information value in CDM2 before investing in production-scale GPU/distributed search.


## F0012 — Theorem-conditioned parity-prefix construction does not enrich post-prefix survival

**Status:** FAILED as a ranker/generator; **COMPUTATIONAL-EVIDENCE** for the finite CDM2-E1 calibration.

CDM2-E1 compared 4,096 deterministic conditioned representatives with 4,096 disjoint controls, exactly matched on `f_K`, in the 60-bit regime with `K=24`.

Survival at 2K was 866/4096 conditioned versus 914/4096 control; at 4K it was 75/4096 versus 71/4096; no representative in either arm survived to the 512-step horizon. Two deterministic matched replication folds disagreed in direction at 4K.

The precommitted reproducibility criterion failed.

**Action:** retain valid parity/debt/preimage/path-merging statements as exact pruning only. Do not advance this construction to CDM3 as a generator.

## F0013 — Debt magnitude adds no information after the conditioning variables are matched

**Status:** FAILED as an independent ranking route; bounded equivalence component **PROVED** for CDM2-E1.

For exactly 60-bit starts and `K<=24`, every-prefix debt positivity is equivalent to exact no-descent through K. Thus a correctly matched K-survivor control necessarily shares the binary debt property.

At 4K, `parity_debt_end` had raw AUC 0.7600 but exactly 0.5000 within `f_K`, because endpoint debt at fixed K is algebraically determined by `f_K`. `parity_debt_min` had within-`f_K` AUC 0.4993.

**Action:** use debt positivity only as the theorem-linked hard screen at its valid scope. Do not rank legal survivors by debt magnitude without new evidence.

## F0014 — Completed odd-to-odd valuation load does not add calibrated persistence information

**Status:** FAILED as an independent ranker in CDM2-E1.

The 4K valuation-load AUC was 0.4869 within `f_K` strata and 0.4952 after further conditioning on debt-min.

**Action:** do not carry valuation load forward as an independent candidate score. Reintroduce it only if a new exact mechanism gives it a different role.

## F0015 — Executable budget guard drift must invalidate an otherwise in-budget run

**Status:** SUPERSEDED first execution; FINITE-VERIFIED process correction.

After CDM2-E1's repository envelope had been reduced to 60 wall/CPU seconds, the first full post-freeze execution finished in about 16 seconds but the committed driver still encoded the provisional 180-second internal guard.

Although actual consumption was below 60 seconds and the later result was identical, that execution was rejected as authoritative. The driver was corrected and the experiment replayed under a code guard matching the frozen declaration.

**Lesson:** an observed run being inside the intended budget is not enough; executable ceilings and declared ceilings must agree before an authoritative campaign result is accepted.
