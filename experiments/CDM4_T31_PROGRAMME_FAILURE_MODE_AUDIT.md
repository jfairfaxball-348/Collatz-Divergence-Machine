## 1. Executive verdict

\[
\boxed{\textbf{MOSTLY YES}}
\]

The Collatz Divergence Machine has fallen into **substantially the same strategic failure model** as the earlier repository `Proof-that-non-trivial-cycles-cannot-exist-in-Collatz`, although with materially better proof-state hygiene and fewer detected mathematical demotions.

The common failure mechanism is not simply “some lemmas were wrong”. It is more structural:

> a difficult root bridge remains open; locally or internally meaningful mathematics is repeatedly generated around that bridge; each solved obstruction narrows or reformulates the surviving class; the surviving boundary is then promoted to the next theorem-sized target; the programme becomes increasingly effective at solving obligations generated by its own previous abstractions, while the probability of closing the original root objective is not shown to increase.

For the earlier cycle repository, the final bounded `FINAL_CHANCE` trial identified the recurring Bridge Problem explicitly: local, finite, branch-restricted, phase, radius, defect, endpoint, and ownership-adjacent information repeatedly failed to force global ordinary ownership. The strongest remaining “middle physical closure” condition turned out not to be an intermediate bridge at all: once integer closure was required, it was exactly the original ownership condition (D\mid Q). The project therefore stopped.

CDM4 is not identical. Its mathematical claims are generally more carefully scoped, and T1–T30 do contain genuine mathematical results. In particular, this audit finds no basis for demoting T1–T30 merely because the strategy is being frozen. The important difference is therefore one of **proof-state quality**, not strategic geometry.

Strategically, however, CDM4 now exhibits the same pattern. Its root objective is constructive:

> find one explicit positive integer whose shortened-Collatz forward orbit is rigorously unbounded and never reaches (1).

Yet the dominant CDM4 theorem programme has evolved into an increasingly broad family of **nonexistence results for positive-integer anchors in structured symbolic languages**. T1–T30 have not produced:

- an explicit anchored aperiodic valuation word;
- an explicit scientific candidate integer;
- a new candidate class with a justified positive probability of containing an anchor;
- a theorem that constructs or recognizes a positive anchor from independently motivated arithmetic data;
- an empirical prediction from the theory that was subsequently confirmed on actual candidate starts;
- a root bridge whose closure probability measurably increased as the symbolic classes expanded.

The T30 residual pushy bounded-letter / neutral-growth pure-morphic class is a mathematically natural residual inside morphic-word theory. But the repository supplies no theorem, heuristic, arithmetic argument, probabilistic model, or empirical evidence that a Collatz counterexample, if one exists, should have a valuation word in that class. At present it is chiefly **the class left over after exclusions**.

Accordingly the strategic classification is:

\[
\boxed{\textbf{C — FREEZE CDM4 / PIVOT}}
\]

This is not a claim that the T1–T30 mathematics is false. It is a decision that continuing the current pure-morphic / recursive-language anchor-obstruction line is no longer a rational default route to the stated root objective.

No CDM4-T32 theorem target is opened by this report.

## 3. Reconstructed failure model of the earlier cycle repository

The earlier repository did not fail in one simple way. The forensic record supports the following decomposition.

### 3.1 Mathematical errors and corrections

There were real correction events, but they were not the whole failure.

The RL349 correction/demotion ledger demoted live half-cycle numerical claims because the required directed source/end orientation and sign assignment had not been proved. It also prohibited importing a historical global height-one theorem from merely local height-one-looking data.

The `FINAL_CHANCE` ledger contains additional numerical-method and coverage repairs: a Session-1 transcription/numerical-method correction, a Session-2 screen that initially omitted admissible profiles, and explicit independent-audit repair before later work continued.

Thus the project did suffer some mathematical/verification defects. But the final STOP verdict did **not** rest on the claim that all previous mathematics was false.

### 3.2 Invalid implication / bridge failures

This was the central recurring failure.

The repository repeatedly had statements of the form:

\[
\text{strong local/finite/branch-restricted structure}
\Longrightarrow
\text{global cycle closure or contradiction}.
\]

The missing implication was often the actual hard theorem.

The historical development records an early local radius-3 obstruction, followed by an exact RL20 countermodel showing that the extracted local grammar did not force an arbitrary cycle to encounter that obstruction. Later Gate A/Gate B, physical-state, endpoint, phase, row, carry, and ownership machinery continued to leave separate global encounter/ownership obligations.

The final `FINAL_CHANCE` programme made this the explicit research object: state a falsifiable Bridge Theorem and attack it directly.

### 3.3 Theorem-scope creep

The repository repeatedly moved from a theorem proved for a local or specially parameterized object toward language suggesting proximity to the global result. The later governance system became stricter precisely because this had happened.

The progress review explicitly warns that:

- local radius results are local;
- branch selectors must be proved for every hypothetical cycle before global use;
- Phase closure is not global cycle elimination;
- R1–R7 is proof architecture, not discharged mathematics.

The existence of these warnings is itself evidence that scope creep had become a recurring risk.

### 3.4 Strategic failure despite locally correct mathematics

The final STOP verdict is strongest here.

By the end, many local results survived. The repository retained exact arithmetic identities, branch reductions, endpoint/profile theorems, boundary collars, finite certificates, and physical-state constraints.

Yet the final frontier was still:

\[
D\mid Q_h,
\]

full ordinary ownership.

The programme had accumulated substantial correct mathematics without obtaining a non-circular route from that mathematics to the unrestricted ownership theorem.

### 3.5 Replacing one missing bridge with another

This pattern is explicit in the historical development:

- radius-3 local obstruction (\to) missing global encounter;
- Gate A / Gate B machinery (\to) separate global reconciliation;
- parent-bridge reductions (\to) residual (\mathcal O_{75});
- half-cycle arithmetic (\to) missing orientation/sign bridge;
- endpoint lifts (\to) missing middle connection;
- two-sided transfer (\to) missing global middle;
- full affine middle (\to) integrality, which is ownership itself.

The final programme concluded that the apparent intermediate bridges were either false or reformulations of the original condition.

### 3.6 Growth of internal terminology and machinery

The repository acquired Gates, R-stages, Phases, ownership languages, q-profiles, decorated interfaces, physical rows, carry geometries, boundary collars, and multiple finite certificate systems.

None of those notions is illegitimate merely because it is internal.

The strategic problem was that later work increasingly used the earlier project's own abstractions as the source of new obligations. The research became excellent at navigating its internal proof architecture while the unrestricted theorem remained outside that architecture.

### 3.7 Increasingly elaborate architecture without root closure

The progress review records R1 at “approximately 94% by theorem-level obligations” while R1 itself remained open and R2–R7 had not been discharged.

That percentage was correctly labelled a project metric, not a mathematical bound. For this audit it is nevertheless a warning sign: a project can become almost complete relative to its **own obligation graph** while remaining far from the root theorem.

### 3.8 Correction/demotion cycles

RL349 is the clearest example: strong live numerics were explicitly demoted after the orientation/sign antecedent failed audit.

The repository deserves credit for preserving those demotions. But recurrent demotion is also evidence that the architecture repeatedly allowed attractive downstream conclusions to form before the load-bearing bridge was secured.

### 3.9 Moving “last obstruction”

The recorded frontier repeatedly changed after substantial work:

radius encounter, Gate reconciliation, parent bridge, Phase 4 residual, orientation/sign, ownership transfer, global middle, then ownership itself.

The final bounded trial was created specifically to prevent this from continuing indefinitely.

### 3.10 True but root-irrelevant lemmas

The repository preserved many valid reductions and finite certificates. The final STOP verdict explicitly did **not** demote them.

The failure was that they did not jointly provide a route to unrestricted ownership.

### 3.11 Self-referential research

By the late stages, later sessions often repaired, refined, bounded, or reparameterized objects created by earlier sessions in the same project.

The final-chance rule prohibited continuing to add local/finite machinery merely as a substitute for attacking the Bridge Problem. This rule is strong evidence that self-referential continuation had become a recognized failure mode.

### 3.12 Insufficient external falsification / independent theorem checking

The repository did introduce independent verifiers, audits, correction ledgers, and an explicit `PROGRESS_REVIEW`. Those are important safeguards.

But most of the long end-to-end architecture remained repository-internal, and the progress review itself marked its claim inventory as not independently audited. The project therefore had stronger internal verification than external theorem validation.

### 3.13 Internal closure as progress metric

The earlier repository's “94% by theorem-level obligations” is the clearest instance.

The final STOP programme replaced internal closure metrics with a harder currency:

> state a concrete Bridge Theorem, attack it, and count failure to produce a real bridge.

That change exposed the strategic weakness.

### Earlier-repository failure model, condensed

The earlier repository's principal failure model was therefore:

> **A missing global arithmetic bridge was surrounded by increasingly elaborate locally correct machinery. Each failure generated a narrower bridge formulation and more internal structure. Progress was often measured by closure of project-created obligations rather than by a demonstrated increase in the probability of proving the root theorem. Once bridge attempts were directly falsified, the surviving “intermediate” condition collapsed back to the original ownership problem.**

That is the comparison standard used below.

## 6. Root-objective distance audit

The root objective is:

\[
\boxed{
\text{Find an explicit positive integer whose shortened-Collatz orbit is rigorously unbounded and never reaches }1.
}
\]

### 6.1 Shortest exact current implication chain

The shortest clean CDM4 chain is:

1. Specify an explicit infinite positive valuation word (a_1,a_2,dots).
2. Prove it is not eventually periodic.
3. Form the exact nested Collatz cylinders / canonical representatives (R_m).
4. Prove the representatives stabilize to one ordinary positive integer (N), equivalently that the anchor carry eventually vanishes under the T2 setup.
5. Conclude that (N) realizes the valuation/parity word.
6. By T2, because the realized word is aperiodic, the positive orbit is unbounded; it also cannot reach (1), whose future is periodic.

This is a genuine bridge.

### 6.2 Which links have advanced?

CDM4 has made substantial progress on:

- defining and analyzing exact cylinders and carries;
- proving that many structured aperiodic words **cannot** satisfy step 4;
- proving broad classes in which bounded (R_m) would force eventual periodicity;
- verifying the consequences of anchoring if it were obtained.

CDM4 has **not** made comparable progress on:

- constructing a word likely to satisfy step 4;
- producing a positive anchor;
- producing an explicit candidate (N);
- identifying an arithmetic signature that positively predicts anchoring;
- estimating a positive density/probability of anchors in a justified family.

### 6.3 Are we measurably closer to one explicit integer?

On the evidence in the repository: **no**.

The number of scientific candidate integers generated by CDM4 theory remains zero. The explicit candidate frontier is still the calibration-only starts 27 and 127, both resolved.

The theory has narrowed where a counterexample **cannot** be encoded if it lies in various finite-state/morphic families. That is mathematical information about a hypothetical counterexample. It has not measurably increased the chance of identifying one explicit integer.

### 6.4 Wrong side of the bridge?

At present, **yes**.

The programme's dominant question has become:

\[
\text{How broad a structured language class can be proved anchor-free?}
\]

The root problem needs at least one instance of:

\[
\text{How can a positive anchor be constructed, recognized, or forced?}
\]

Those are not symmetric tasks. Excluding increasingly broad low-complexity symbolic classes can continue indefinitely while never supplying the constructive object.

## 7. Negative-result ratchet

The programme exhibits the following repeated pattern:

1. define or inherit a structured symbolic class;
2. derive exact Collatz coding/scalar machinery for it;
3. prove that a genuinely aperiodic member cannot have a positive-integer anchor, or reduce the problem to a sharper internal obstruction;
4. move to a broader or more singular class;
5. construct new technical machinery for the newly surviving features;
6. again exclude that class or isolate the next boundary;
7. designate the new boundary as the next theorem-sized obligation.

Examples include:

automatic (\to) higher-rank automatic (\to) finite abelian/nonabelian kernels (\to) generic balanced finite kernels (\to) multivariate/unbalanced (\to) singular incidence/stable image (\to) nonprimitive (\to) variable-length morphic (\to) unequal-growth multiscale (\to) divisor-relative (\to) nonprincipal moving-target (\to) erasing/non-growing normalization (\to) pushy bounded-letter residual.

This is a **negative-result ratchet**.

### Principled stopping rule before T31

The repository had excellent compute-budget stopping rules and periodic correction audits. It did **not** have a comparable stopping rule for theoretical class broadening.

Nothing in the prior rules said, for example:

> after (k) successful class exclusions without a positive anchor mechanism, stop expanding the symbolic hierarchy.

Therefore the process was structurally capable of continuing from pure morphic to pushy morphic to (S)-adic or still broader languages indefinitely.

That is a strategic defect.

T31 repairs it by freezing the line.

## 11. AI research-loop / selection-effect audit

The risk described in the T31 prompt is strongly supported by the trajectory.

The interaction pattern has been:

1. the current report ends with an “exact next theorem-sized obligation”;
2. the next session is instructed to attack that obligation;
3. a reasoning model can usually identify a technically meaningful adjacent refinement;
4. the refinement creates new definitions, exceptional cases, or boundary strata;
5. closure of that target legitimizes another adjacent target;
6. the sequence therefore remains indefinitely productive in the local sense.

This creates a selection effect.

The research process preferentially observes targets that are:

- close enough to the current machinery to be attackable;
- rich enough to support a theorem-sized result;
- generated by the failure boundary of the previous theorem.

That is not the same selection criterion as:

- highest expected information gain about the existence of an unbounded Collatz orbit;
- highest probability of producing an explicit positive anchor;
- highest probability of producing an explicit candidate integer.

The earlier cycle repository showed the same phenomenon at much greater scale: increasingly precise internal targets and proof architecture continued to exist even though the global ownership bridge was not becoming more plausible.

CDM4's stronger governance reduced false promotion, but it did not eliminate this selection effect.

### Diagnostic conclusion

The AI-assisted continuation loop is **SEVERE** as a strategic risk.

A theorem-sized checkpoint is a good unit of mathematical work. It is a bad automatic criterion for deciding what research question should be asked next.

## 12. T30 surviving-space significance

T30 leaves the pushy bounded-letter / neutral-growth pure-morphic class.

This class is independently natural **inside morphic combinatorics** because Pansiot's growth/complexity dichotomies distinguish bounded-letter recurrence and because T30 gives an explicit quadratic-complexity pure morphic witness outside the growing-substitutive normalization class.

That establishes mathematical naturalness.

It does **not** establish Collatz relevance.

The repository does not provide:

- a theorem that valuation words of hypothetical counterexamples must be morphic;
- a theorem that they must be pure morphic;
- a theorem that surviving anchors are more likely in pushy systems;
- arithmetic evidence favouring recurrent bounded-letter runs;
- empirical evidence from high-magnitude starts suggesting pushy morphic structure;
- a probabilistic model assigning elevated anchor probability to the residual;
- a candidate-generation procedure that maps the residual to explicit promising integers.

Therefore:

> the T30 residual is a natural residual class, but not an independently motivated candidate class.

That distinction is decisive.

“Everything simpler has been excluded” is not evidence that the remaining class is promising.
