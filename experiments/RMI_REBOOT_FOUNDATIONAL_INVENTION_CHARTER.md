## 4. Why a new programme is justified despite both freezes

The two freezes establish strong negative design information:

1. a broad symbolic hierarchy can generate valid mathematics without improving the constructive ordinary-integer bridge;
2. a natural integer-return template can be structurally impossible;
3. relaxing a failed template can merely reproduce Collatz in new coordinates;
4. finite multi-state affine recurrence can retain the same denominator obstruction;
5. necessary residue/stopping-time constraints need not generate an orbit;
6. finite prefixes do not regenerate themselves.

None of these results proves that no finite regenerative ordinary-orbit certificate can exist.

The repository has therefore learned something more specific than "the problem is too hard":

> it lacks a mathematical object that carries a finite amount of exact information along one ordinary forward orbit, regenerates enough of that information after a finite genuine evolution, and certifies irreversible physical growth without merely re-encoding unrestricted Collatz dynamics.

That missing capability is a legitimate first-principles research target.

The freeze logic prohibited **automatic class succession**. It did not prove that mathematics already contains every useful concept. RMI is justified precisely because it changes the object-selection rule from mathematical adjacency to root capability.

## 5. Template escalation versus foundational invention

### Unjustified adjacent generalization

Examples remain disallowed unless separately root-derived:

- affine failed -> quadratic;
- one state failed -> three states;
- modulus 64 failed -> modulus 128;
- finite partition failed -> larger automaton;
- integer coefficients failed -> rational coefficients;
- one parameter failed -> two parameters;
- morphic failed -> S-adic;
- one completion failed -> a larger completion.

The common defect is that the successor is selected because it is the next expressive superset.

### Root-derived foundational invention

A new object is eligible when the order of reasoning is:

1. identify a precise root-level inability;
2. state the proof capability that would remove it;
3. derive the minimum axioms required for that capability;
4. invent the smallest object satisfying those axioms;
5. preserve ordinary forward-orbit ownership from the start;
6. give the object a finite kill condition;
7. test whether success would shorten the root implication chain.

The new object may be unprecedented. Prior naming is not an authorization requirement.

## 6. RMI founding philosophy

RMI adopts the following mentality:

> Mathematics may not presently possess the language needed for this problem. That is not a reason to stop. It is a reason to invent the language.

Operationally:

> Our task is not merely to search the existing mathematical toolbox for a Collatz proof. Our task may be to create mathematical machinery that makes such a proof possible.

This does not relax proof standards. It raises the design freedom while tightening accountability to the root objective.

The governing discipline is:

> Invent boldly, but every invention must remain accountable to one actual ordinary forward orbit and to the root objective.

The governing selection question is:

> What mathematical capability does a proof of an explicit unbounded Collatz orbit require that our present mathematics does not possess, and what is the smallest new structure we can invent to supply it?

Not:

> What is the next known mathematical class we can generalize into?

## 11. Root-derived capability specification

A successful RMI structure is not required to use any existing named formalism. It should satisfy the smallest useful set of capabilities below.

### A. Ordinary-integer ownership

The structure attaches directly to one ordinary positive integer state, or to an explicit ordinary-positive family whose members and transitions are exact.

No later anchoring theorem is allowed as the decisive bridge.

### B. Forward exactness

Every promoted transition corresponds to a genuine finite segment of the actual shortened-Collatz forward orbit.

### C. Finite description

At each certified stage, the proof state has a finite mathematical description.

The global state space need not be finite.

### D. Regeneration

After a finite genuine forward evolution, enough of the proof state reappears to continue the same certification logic.

Literal state equality is not required. RMI is explicitly allowed to invent weaker but composable notions of recurrence.

### E. Physical growth

The regenerated state certifies growth of a quantity belonging to the actual integer orbit or an exact proper function of actual orbit states.

Pure bookkeeping growth is rejected.

### F. Properness / irreversibility

There is a quantity, order, filtration, obstruction count, scale, or other exact device preventing infinitely many certified regenerations inside a bounded physical region.

Stepwise monotonicity is not required.

### G. Non-tautology

The structure must do more than store the current integer and replay unrestricted Collatz iteration.

A successful structure compresses future proof obligations: its finite carried information must imply something not obtained merely by renaming the map.

### H. Root compression

Success must shorten or materially simplify the implication chain to an explicit unbounded ordinary orbit.

### I. Killability

Every candidate structure has a finite theorem, counterexample, bounded exact test, or logical collapse condition that can show it lacks the intended capability.

### J. Anti-hierarchy rule

Failure of one invented object does not authorize a larger version. A successor must again be derived from the unresolved capability.

## 15. RMI invention methodology

Every numbered RMI research session uses the following lifecycle.

### Phase 1 — obstruction extraction

State exactly one root-level inability exposed by the repository.

Example:

> arbitrarily long exact growth prefixes can be certified, but no finite carried information is known to regenerate the growth condition after the forced prefix is consumed.

### Phase 2 — capability specification

Before naming an object, state what a hypothetical object must be able to prove to remove that obstruction.

### Phase 3 — minimal invention

Invent the smallest structure that could provide that capability.

Do not add expressive power for convenience or generality.

### Phase 4 — toy exact tests

Use exact small identities, known ordinary trajectories, simplified maps, symbolic algebra, or bounded state enumeration only to validate or falsify the concept.

Toy success is not evidence of Collatz divergence.

### Phase 5 — root connection

Write the shortest implication chain from the invented object to one explicit unbounded ordinary orbit.

Count unresolved nontrivial arrows.

### Phase 6 — hostile collapse test

Test whether the invention is secretly:

- a coordinate rewrite of Collatz;
- a finite-prefix condition;
- a 2-adic anchor problem;
- a symbolic ownership problem;
- a backward-tree representation;
- a larger failed template;
- a bookkeeping height detached from physical orbit values;
- or an internally self-renewing theory with no candidate leverage.

### Phase 7 — kill or promote

Promote only after the object acquires a theorem-level capability unavailable before.

Otherwise record the failure and return to the root obstruction, not automatically to a more elaborate object.

### Safeguard 6 — root-arrow accounting

A session may contain substantial mathematics and still count as strategically null if the root chain is not shortened and no new theorem-level capability is obtained.

### Safeguard 8 — bounded successor argument

Any proposed next invention must name the failed capability it repairs and why that repair is minimal.

## 24. Exact criteria for killing RMI

Kill RMI immediately or at the stated gate if any applies:

1. **RMI-3 gate failure:** no candidate structure satisfies all seven RMI-3 conditions.
2. **Tautology collapse:** surviving structures merely encode unrestricted Collatz evolution and add no proper regenerative theorem.
3. **Finite-prefix collapse:** all apparent growth is exhausted after preselected finite parity/valuation data.
4. **Ownership collapse:** the proof state ceases to belong to one actual ordinary forward orbit.
5. **Completion collapse:** the decisive recurrence exists only in a completion/formal space without an ordinary-positive theorem already in hand.
6. **Backward-direction collapse:** the structure certifies predecessor/inverse membership rather than one forward orbit.
7. **Bookkeeping collapse:** the only monotone quantity can grow while the physical orbit remains bounded.
8. **Template-ladder relapse:** successive sessions enlarge representations without a root-derived capability reason.
9. **No finite falsifier:** a candidate object cannot state what finite mathematical result would kill it.
10. **Self-renewing theory:** two consecutive sessions create mainly new internal terminology/obligations with no new theorem-level root capability.
11. **RMI-6 arrow failure:** unresolved nontrivial root-arrow count remains 2 and no root certificate exists.
12. **Compute substitution:** a proposed continuation requires a scientific trajectory campaign before a theory-derived prediction exists.
